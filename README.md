一款用 Godot 4 做的塔防小游戏：建塔守住据点，别让入侵者摧毁宝石。
  - 怪物沿固定路径进攻据点，你在路径旁建塔防守
  - 据点 HP 归零则失败；撑过全部波次并清空怪物则胜利
  - 有 HP 和 EXP（金币）系统，打败怪物拿 EXP
